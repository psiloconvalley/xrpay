# Architecture Decision Records (ADRs)

This directory records significant architectural decisions made during the design and evolution of `xrpay`.

Each ADR follows the format:

- **Context** — What forces are at play?
- **Decision** — What did we decide?
- **Consequences** — What are the tradeoffs?

ADRs are numbered sequentially and are immutable once merged. If a decision is reversed, a new ADR supersedes the old one.
